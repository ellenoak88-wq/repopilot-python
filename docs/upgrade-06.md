# 第六轮扩展：保留历史的同步与跨仓库学习档案

这一轮把“当前源码索引”和“个人学习经历”分开保存。更新项目不会清除旧会话，经过人工整理的经验可以在其他会话和仓库中复用。

## 仓库同步

- 项目页点击 **同步仓库**，按当前导入上限读取默认分支的新 commit。默认 1,000 文件、50 MB；此前只导入 100 个文件的项目可以在这里扩容。
- 比对 Git blob SHA，复用内容未变的本地文件，仅下载新文件和变化文件。索引保存是单个 SQLite 事务，任务整体失败时原索引保持不变。
- 显示新增、更新、移出当前索引和未变化数量。“移出”可能来自文件删除、过滤条件或导入预算，不能据此断言文件已从 GitHub 删除。单文件读取失败仍可产生部分索引，界面会明确提示。
- 手动重新导入同一仓库也保留会话；仓库名称大小写不同会复用已有记录。发现页继续直接打开已导入项目。
- 每条新回答记录 commit 和索引版本。旧回答的源码摘录永久保存在回答中；索引变化后，点击旧引用查看原摘录和固定 commit 的 GitHub 链接，不打开当前文件的同一行。
- 旧版本回答不进入当前源码的对话上下文，也不能直接重新生成；可重新发送问题。上手清单和向量索引保留，内容或 commit 变化后沿用原有过期提示，需要显式重新生成/建立。

## 学习档案

1. 在任意已完成回答下点击 **存为学习档案**，生成待确认草稿；也可从侧栏 **学习档案 → 新建档案** 手动记录。
2. 整理标题、内容、适用条件、标签和类别。类别支持实践经验、概念理解、操作步骤。
3. 选择 **项目专属** 或 **跨仓库通用**。专属档案只用于关联项目；通用档案可以在其他项目中召回，来源仍保留。
4. 人工核对后设置为 **已验证**。没有适用条件不能标记为已验证。待确认、归档及来源已过期的档案不自动参与问答。
5. 使用搜索、来源仓库、状态、范围和类别筛选；每页 20 条。可导出全部档案为 Markdown，包含状态、适用条件、来源 commit 和引用链接。

档案独立于会话保存。删除源会话不删除档案，档案详情保留原问题、回答、源码摘录以及当时使用的学习经验快照。重复保存同一版本的回答会打开已有档案；重新生成后的不同回答可另存。

来源仓库不可在编辑时替换；可以改变使用范围。关联仓库的索引变化后，档案标记为需复核，原始来源不会被改写。核对当前源码后勾选复核并保存，即可再次使用。保存和删除均检查修订号，避免多个页面互相覆盖。

## 问答中的经验复用

问答区默认勾选 **参考已验证的学习档案**。服务端以 BM25 在符合范围的有效档案中检索最多 4 条，每条内容最多 1,500 字，并附带适用条件。源码仍使用已有的 BM25 / 本地向量混合检索。

- `[S1]` 等标记指向当前源码证据。
- `[M1]` 等标记指向个人历史经验，回答下有独立的档案快照和查看入口。传给模型的说明要求将跨仓库经验作为类比，并用当前源码核对事实和命令。
- 检索模式不调用生成模型，会单独展示相关经验的原文摘录。
- 关闭开关后不召回档案；包含这些经验的旧回答也不会重新送入模型上下文。已编辑、归档、删除或过期档案的旧引用同样不会通过历史回答重新进入上下文。
- 保存的回答保留当时实际提供给模型的档案快照，后来修改档案不会改变旧回答的记录。这表示“提供的参考材料”，不保证模型在每句话中都使用了它。

这是一套结构化个人记忆和可导出的 Wiki 素材，不会训练或微调模型。当前不自动从全部聊天提炼结论、不自动合并冲突笔记，也不自动生成完整项目 Wiki。先人工维护可信档案，后续可基于这些档案生成专题页面和学习地图。

## 数据与升级

`learning_records` 与源码、会话共用现有 SQLite 数据库，不增加外部服务或模型下载。原生前端、Python 版本及 Docker 使用相同功能。首次启动补充索引版本，并将旧回答的版本标为“迁移时推定”；旧数据库本身没有逐条回答的 commit 信息，因此不能当作独立验证过的版本来源。

更新前建议使用已有在线备份工具，目标文件必须不存在：

```powershell
uv run python -m repopilot.migrate --source data/repopilot.db --destination work/backups/before-learning.db
docker compose up -d --build --wait
```

数据库包含个人笔记，仍写入现有持久化数据目录，不上传到 GitHub。回滚应用时保留备份；恢复数据库前先停止容器，避免覆盖正在使用的 SQLite 文件。

## 验证

本轮测试覆盖增量下载、事务回滚、会话保留、旧引用版本隔离、跨仓库召回范围、归档/过期排除、修订冲突、复核、来源快照与重启持久化。浏览器验证包含保存草稿、编辑确认、跨仓库引用、召回开关、Markdown 下载、旧引用展示和 390px 手机布局。
