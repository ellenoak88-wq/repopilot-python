# 第二轮扩展：仓库导航与代码搜索

## 使用方式

打开一个已导入仓库，在右侧切换「项目文件」和「代码搜索」。

- **项目文件**：按目录浏览源码，点击目录名称展开或折叠，也可全部展开/折叠。路径筛选会自动展开匹配文件所在目录。
- **关键词搜索**：输入函数名、接口路径或代码片段，不区分大小写，按原文匹配；标点符号按普通文本处理，不执行正则表达式。
- **相关片段**：适用于「如何安装启动」「路由入口」等问题，使用 BM25 和中文查询扩展返回相关代码、文档。
- **路径筛选**：例如 `src/`、`.py`、`README`，只在匹配路径的已索引文件内搜索。
- **结果定位**：预览显示原文件行号和关键词高亮，点击结果标题打开源码阅读器并定位命中行。

搜索独立于聊天，不调用模型、不消耗模型 Token，也不创建对话记录。生成回答期间仍可浏览文件和搜索。切换仓库会清空搜索，并取消未完成的旧请求。

## 范围与限制

仅搜索当前 commit 已索引的文件，部分索引会显示提醒；没有命中不代表整个 GitHub 仓库都没有相关代码。界面默认显示前 20 个结果，结果较多时可缩短路径范围或换更具体的关键词。

关键词模式会合并相邻命中，相关片段模式去除同一文件中重叠的片段。预览最多显示 8 行，每行最多约 320 字符；完整代码仍可在源码阅读器查看。

## API

`GET /api/search?repo=owner/repo&q=addNote&mode=literal&path=src/&limit=20`

`mode` 可为 `literal` 或 `ranked`；`q` 为 1–200 字，`path` 最多 200 字，`limit` 为 1–50。返回命中片段、预览行号、定位行号、片段总数、命中文件数、当前 commit 及部分索引标记。

接口复用本地同源限制和仓库索引，不读取任意本机路径，也不执行检索到的源码。无需数据库迁移或额外配置。

## 验证

新增 10 项自动测试，覆盖关键词与符号匹配、相邻命中合并、中文相关检索、长行预览、结果上限、参数校验和仓库隔离。现有及新增测试合计 38 项通过。

浏览器验证覆盖目录树、路径筛选、两种检索模式、正确行定位、无结果提示、过期请求丢弃、HTML 源码安全显示、键盘标签切换及 390px 手机布局。
