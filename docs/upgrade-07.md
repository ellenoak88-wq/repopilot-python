# 第七轮扩展：项目分区与会话菜单（v0.8）

## 项目分区

侧栏点击 **管理分区**，可创建、重命名分区，并在“项目归属”中移动项目。项目页也可以通过 **所属分区** 下拉框移动当前项目。每个仓库属于一个分区，或保持未分区；侧栏按分区分组，支持折叠。

分区归属独立于源码索引保存，重新同步仓库不会改变归属。删除分区前需先移出项目，并修改该区共享档案的范围。非空分区会拒绝删除，不会连带删除项目、会话或学习档案。分区名称最多 60 字，同名分区不能重复创建。

## 分区共享学习档案

学习档案现在有三个范围：

| 范围 | 可在何处引用 |
| --- | --- |
| 项目专属 | 仅来源项目 |
| 分区共享 | 仅所选分区内的项目 |
| 跨仓库通用 | 所有项目，包括其他分区及未分区项目 |

在已加入分区的项目中，点击回答下的 **存为学习档案**，新草稿默认选择该分区共享；仍需填写适用条件、核对内容并标记为已验证后才参与问答。已保存过的回答会打开原档案，不自动更改其范围。

已有项目专属档案保持原范围。要共享它们，请在学习档案页编辑，将使用范围改为“分区共享”并选择分区。档案可按共享分区筛选，回答中的经验快照也会显示当时的分区名称。

移动项目不会迁移已保存的共享档案：档案固定留在选定分区，来源仓库和原始证据不变。移动后的项目立即按新分区召回经验；原分区经验也不会通过旧回答重新进入模型上下文。需要转移档案时，显式编辑其共享分区。未分区项目不会因为都未分区而互相共享；“跨仓库通用”档案仍按原规则全局可用。

待确认、归档或来源已过期的档案仍不参与自动召回。分区是个人工作区中的组织方式，当前应用仍是本地单用户模式。

## 会话列表与菜单

项目页将原会话下拉框改为可搜索的会话列表。每条会话右侧 **⋯** 菜单支持：

- **置顶会话 / 取消置顶**：置顶优先，同一组内按最近更新时间排序；刷新和重启后保留，搜索结果也遵循此顺序。
- **重命名会话**：保留原有重命名能力，操作指定行的会话。
- **删除会话**：确认后仅删除指定会话及其对话，已保存的学习档案保持独立。

置顶和删除非当前会话不会切换当前会话或清空未发送的问题。删除当前会话后打开排序靠前的剩余会话；删除最后一个会话会自动创建一个未置顶的默认会话。打开仓库时优先选择置顶会话，没有置顶时打开最近更新的会话。

菜单支持 Enter/Space 打开、上下方向键切换操作、Escape 关闭并将焦点返回菜单按钮；点击菜单外也会关闭。手机页面仍可使用分区列表和会话菜单。

## 数据与验证

SQLite 新增 `project_sections` 和 `repo_sections` 表；`sessions` 自动补充 `pinned` 列，现有会话默认未置顶。现有学习档案不自动修改。Docker 沿用原数据目录，没有新增外部服务或模型依赖。

升级前可使用在线备份工具，目标文件须不存在：

```powershell
uv run python -m repopilot.migrate --source data/repopilot.db --destination work/backups/before-sections.db
docker compose up -d --build --wait
```

本轮自动化测试覆盖分区共享边界、移动后的上下文隔离、私有范围保留、非空分区保护、并发修改冲突、置顶排序、会话跨仓库校验、删除最后会话及旧库迁移。浏览器验证覆盖创建与归组、实际问答召回、单条会话菜单、置顶持久化、搜索、键盘关闭和手机布局。


## v0.8.1：左侧项目条目和分区菜单、拖放归组

截图中的左侧条目（例如 `Tencent/LoopForge`）代表已索引项目。现在这些条目右侧同样有 **⋯** 菜单，支持 **置顶项目 / 取消置顶**、**移动到分区…** 和 **删除本地项目**。项目置顶在所属分区内排序，独立于项目内部会话的置顶，刷新、重启和源码同步后仍保留。

每个分区标题右侧也有 **⋯** 菜单：自建分区支持重命名、删除空分区和管理；“未分区”支持新建分区和管理，不能重命名或删除。

桌面端可按住左侧项目名称，拖到目标分区的标题或内容区域。目标会高亮，折叠分区会展开，松开即保存；也可以拖回“未分区”。拖动不会切换当前项目、清空未发送的问题或移动已保存的档案。失败或并发归属变化时会显示错误并刷新列表。手机端或键盘操作可用菜单中的“移动到分区…”选择目标。

**删除本地项目** 会明确要求确认，并删除该项目的本地源码、全部会话、上手清单、向量索引与分区归属；不会删除 GitHub 仓库。已保存的学习档案和原始证据快照保留，因来源缺失而停止自动召回，仍可编辑为待确认或归档。删除当前项目后回到导入页，删除其他项目不影响当前会话。

SQLite 新增 `repo_preferences` 保存侧栏项目置顶。升级无需重新导入项目，无需新依赖。回归验证覆盖 113 项 Python 测试，以及真实拖放、折叠分区、移回未分区、菜单定位、手机端移动、刷新持久化和删除后的学习档案保留。
